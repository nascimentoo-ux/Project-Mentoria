# Elite40+ — Landing

Landing page da consultoria **Elite40+** (Marcos Aurílio).

## Ver em tempo real

```bash
npm install
npm run dev
```

Abra: [http://127.0.0.1:43123/index-v2.html](http://127.0.0.1:43123/index-v2.html)

O Vite recarrega a página automaticamente quando o `index-v2.html` é salvo.

## Arquivos principais

- `index-v2.html` — página completa (edite este)
- `assets/` — imagens (`elite40-shield.png`, `trainer-photo.png`)

## Observação

Sem as imagens em `assets/`, o layout aparece, mas os espaços de foto ficam quebrados até você adicionar os arquivos.
